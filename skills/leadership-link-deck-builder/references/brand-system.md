# Leadership-Link brand and visual system

These values are the authoritative Leadership-Link standard, taken from Eileen's operating
profile (`skills/eileen-operating-profile/SKILL.md`) and the approved template
(`assets/Leadership-Link_Deck_Template.potx`). The operating profile is the source of
truth; if this file ever disagrees with it, the profile wins. When the approved template
and this specification appear to disagree, prefer the template.

Note on drafts: some circulating program decks use an off-brand palette (a #1C1E43 navy
family) and Merriweather. Those are drafts, not the standard. Do not copy their brand.
The real standard is below.

## Core colors

- Navy `#0A1F44` (primary; carries 60-70% of the visual weight across a deck)
- Orange `#F2541B` (accent; headings, rules, calls to attention, the "do this" side)
- Gold `#D4AF37` (secondary accent; stats, source lines, secondary emphasis)
- Lime `#A6CE39` (tertiary accent; energy and positive-signal moments, used sparingly)

Never give the four colors equal weight. Navy dominates. Supporting neutrals from the
template include paper tint `#F5F7FA`, muted grays `#6B7488` and `#8A96B0`, a lighter navy
`#12295A`, white `#FFFFFF`, and black `#000000`.

## Typography

- Font: **Tahoma** across all deliverables (decks and documents alike). Do not substitute
  Merriweather, a decorative face, or a generic technology font.
- Use sentence case for body; the template applies uppercase only to small muted
  structural labels.

## Minimum sizing

- **PowerPoint: 18pt floor, always.** Nothing on a slide renders below 18pt except a
  footnote or source citation. If text will not fit at 18pt, the slide has too many words:
  cut words, do not shrink type.
- **Everywhere else (Word, PDF, HTML, footers, captions, table cells, page numbers): 10pt
  minimum.**
- The one 11pt exception is a muted, non-substantive structural label (a small uppercase
  letter-spaced tag that orients without competing). Never use it for body copy,
  instructions, evidence, model definitions, or participant actions. When in doubt, keep
  everything at 18pt+ and drop the tag.

## Footer

Approved footer convention on all decks and documents:

```
Leadership-Link | Eileen Habelow, PhD
```

Domains: `leadershiplink.com` and `leadershiplinkondemand.com`. Preserve the approved logo
and capitalization treatments exactly; never recreate the wordmark when the template
provides the approved asset.

## PowerPoint layout system (default for every deck)

The governing instinct: **lots of visuals, few words, one idea per slide.** A deck is a set
of anchors the presenter talks over, not a document read off the screen. Apply this by
default; do not ask whether to use it.

- **One idea per slide.** Two points means two slides.
- **A visual on every slide.** An icon, a large number, a diagram, a comparison pair, or a
  shape composition. A text-only slide is a defect.
- **Dark/light sandwich.** Title, section breaks, hero/equation moments, and closing/recap
  slides use navy `#0A1F44` with white text. Content slides use white with navy text.
- **Cards, not bars.** Set content apart with rounded-rectangle cards (rectRadius
  ~0.12-0.14) on a subtle paper tint or color-tinted fill with a soft shadow. Never use
  edge accent stripes, sidebar bars, or under-title accent rules.
- **The motif (permanent):** flat line/solid icons seated inside a circle (white circle on
  light slides; a lighter-navy circle on dark slides), consistent across the deck. The icon
  color must contrast with its circle: navy on white circles, a bright accent (gold,
  orange, or lime, never navy) on lighter-navy circles.
- **The logo:** large upper-left on the cover; smaller top-right on section headers,
  dividers, Mission, and Thank You. Not on every content slide (the footer carries the
  wordmark in text). Use the full-color logo on light backgrounds and the white-knockout
  logo on navy; never place the navy-text logo on a navy field.

The approved `.potx` encodes the full layout vocabulary (title, agenda, section header,
numbered divider, content-with-icon, two-column comparison, text+visual, three-up cards,
five-item row, process flow, stat/hero, single-stat, big-quote, closing/recap) plus the
standard workshop slides. Reuse it by chrome inheritance (duplicate a branded slide,
replace only text); do not rebuild brand from memory. See `SKILL.md` and the operating
profile for the standard workshop slide set and speaker-note rules.

## Visual standards

Use whitespace, clear hierarchy, restrained emphasis, diagrams that carry instructional
value, and one central message per slide. Avoid generic corporate AI imagery, decorative
icons, dense text walls, unapproved fonts, excessive gradients, clutter, and layouts that
resemble reports. A slide that looks like a page of a document has failed the standard even
if every fact on it is correct.
