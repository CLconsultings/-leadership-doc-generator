# Red Flag Run evaluation

Run after an edit or final audit. Use pass/fail internally. Fix only failed checks.

## Meaning and evidence

1. Is the writer's actual point unchanged unless the user explicitly asked to change it?
2. Were no unsupported facts, statistics, quotations, examples, sources, outcomes, or causal
   claims added?
3. Are fact, supported conclusion, inference, and speculation still distinguishable where
   the distinction matters?
4. Was useful uncertainty preserved rather than polished into certainty?

## Authorship and provenance

5. Were known human-authored phrases preserved unless a concrete reason required change?
6. Did the edit avoid guessing authorship from style alone?
7. If provenance was uncertain, did the edit avoid inventing attribution?
8. Would the writer recognize the vocabulary, cadence, bluntness, restraint, humor, and
   degree of polish as their own?
9. Did the edit avoid fake imperfections or deliberate detector-evasion tactics?

## Minimum effective edit

10. Were strong original sentences left alone?
11. Is the amount of rewriting proportional to the actual problems in the draft?
12. Was the writer's structure preserved unless structure itself was causing confusion,
    repetition, or a formulaic pattern?
13. Did the edit stop before it became general stylistic polishing?

## Pattern quality

14. Do generic sentences pass the portability test or have a specific reason to remain?
15. Were formulaic openings, transitions, contrast structures, rhetorical setups, and
    endings repaired where they actually weakened the draft?
16. Does the final piece avoid clustered robotic symmetry, stacked punchy fragments, and
    repeated three-part cadence unless those are characteristic of the writer?
17. Were abstract benefit claims replaced with mechanisms, consequences, or evidence only
    when the source material supports the replacement?
18. Were named-source problems flagged rather than solved by invented attribution?

## Composition

19. Did any governing domain, evidence, brand, framework, legal, or confidentiality skill
    retain priority over this writing layer?
20. If this is Leadership-Link work, does Eileen Intelligence still control the reasoning,
    framework language, coaching posture, and approved voice?

## Output

21. Did the response follow the requested destination and format rather than adding an
    automatic audit appendix?
22. For detect mode, were findings tied to actual excerpts and named patterns without a
    numeric AI score or authorship claim?
23. For final-audit mode, were unresolved evidence, provenance, or authorization issues
    surfaced only if they could still change the decision to publish?
