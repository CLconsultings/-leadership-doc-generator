# Corrections Log and release standard

This file holds two things that must both be retained: the Corrections Log and the
"What Great Looks Like" release standard. Calibration examples support judgment but do
not replace either of these.

Apply the Corrections Log internally on every deck. Never expose it in client-facing
work. The authoritative version of these lessons lives in Eileen's operating profile
(`skills/eileen-operating-profile/SKILL.md`); this file carries them for the production
workflow and adds deck-specific entries.

## What Great Looks Like (release standard)

Great work feels like Eileen, not like AI. A senior peer who has known her for ten years
should read a deliverable and recognize it as unmistakably hers in voice, framing, and
judgment. A successful output:

- reflects Eileen's actual reasoning and names the real leadership tension
- produces practical behavioral guidance
- preserves approved framework language
- distinguishes verified content from inference
- protects client confidentiality
- uses the approved Leadership-Link design system (Tahoma, real palette, real footer,
  visual-first layout, template chrome)
- remains editable native objects
- includes useful speaker notes on every slide
- is visually clean and presentation-ready
- contains no invented curriculum and no generic leadership language

A polished output that violates framework fidelity is not acceptable. An incomplete output
that clearly identifies a source gap is preferable to a complete-looking fabrication.

## Corrections Log

When a correction is confirmed: record the failed behavior, record the required behavior,
generalize the lesson only when appropriate, and use the entry to prevent the same failure
in future output.

### Standing lessons (from the operating profile)

1. **Overly verbose responses.** Keep concise, essential, executive-level. High-density
   insights only.
2. **Emojis.** Never use them.
3. **Fabrication or inferred gaps.** Do not invent. State uncertainty. Use only verified or
   provided information; mark gaps `[VERIFY]`.
4. **Early judgment in coaching tone.** Start with curiosity and partnership. Sequence:
   curiosity, then alignment, then directness.
5. **Salesy workshop content.** Replace with honest survey framing and psychological safety
   language.
6. **Building PowerPoint slides from scratch when chrome exists.** Duplicate an existing
   branded slide and replace only text. Preserve chrome inheritance.
7. **Scripted deflection on personal disagreement.** When teaching how leaders handle
   disagreement with an organizational decision, be direct and brief, then move to the work.
