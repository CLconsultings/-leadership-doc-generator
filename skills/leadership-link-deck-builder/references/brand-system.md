# Leadership-Link brand and visual system

Apply this whenever you make a visual decision on a Leadership-Link deck. When the
approved template and this specification appear to disagree, prefer the template: it is
the current approved source, and this file describes it rather than overriding it.

## Core colors

- Navy: `#1C1E43`
- Orange: `#ED8344`
- Grey: `#999999`
- Light blue: `#BAD3E9`
- Purple: `#5D386C`
- Green: `#9BBB59`

Where the current approved template uses later signal colors, preserve the template
rather than substituting these values by hand. Do not introduce colors outside the
approved system for emphasis or decoration.

## Typography

- Use Merriweather where the template and Leadership-Link brand standards require it.
- Use sentence case, not title case or all caps, for headings and body.
- Avoid decorative or generic technology fonts. The brand reads as considered and
  human, not as a default slide-tool aesthetic.

## Minimum sizing

- Standard body content: minimum 18 pt.
- Structural labels may use 11 pt only when they are muted, non-substantive navigation
  or classification elements (for example a small section tag or a slide classification
  marker).
- Do not use the 11 pt exception for body copy, instructions, evidence, model
  definitions, or participant actions. If a reader needs to act on the text or learn
  from it, it is body content and must meet the 18 pt minimum.

## Footer

Use the approved footer treatment:

```
Leadership-Link | Ask AI-Leen
```

and, where required:

```
powered by know2grow.com
```

Preserve the approved logo and capitalization treatments exactly. Do not restyle the
wordmark, change its capitalization, or substitute a recreated logo when the template
provides the approved asset.

## Visual standards

Use whitespace, clear hierarchy, restrained visual emphasis, diagrams that carry
instructional value, behaviorally meaningful imagery, and one central message per slide.

Avoid generic corporate AI imagery, unnecessary stock icons, decorative diagrams with no
instructional value, dense text walls, unapproved fonts, excessive gradients, visual
clutter, and slide layouts that resemble reports. A slide that looks like a page of a
document has failed the visual standard even if every fact on it is correct.
